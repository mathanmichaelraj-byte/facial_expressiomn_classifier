About This Project

Facial Expression Classification using CNN Deep Learning

This project implements a deep Convolutional Neural Network (CNN) for classifying human facial expressions into 7 categories:

  • Angry
  • Disgust
  • Fear
  • Happy
  • Neutral
  • Sad
  • Surprise
Features
  • Deep CNN architecture with multiple convolutional blocks, batch normalization, and dropout
  • Data augmentation for improved generalization
  • Real-time face detection using OpenCV Haar Cascades
  • Live webcam feed with on-the-fly classification
  • Image upload with multiple face detection support
  • Confidence scores and probability distribution
  • Comprehensive training pipeline with callbacks
  • Exception handling and logging throughout
Technologies Used
Python TensorFlow/Keras OpenCV Flask NumPy Scikit-learn
